# Website (Jaspr)

Design: 10.1–10.5, 10.9, 10.10, 10.11, 3.2, 13.5 · Milestone: M3, M4 · Code: `website/`

## Ki kore

Customer er website: Jaspr server mode e protiti page server e render hoy (SSR), dokan chena jay `Host` theke. Bangla root e, English `/en/...` e. Browser kokhono Go API te jay na; page er data Jaspr server API theke ane.
Ache: config, request theke API client, `Cache-Control`, BFF, settings cache, theme/font, layout (header, bottom nav, footer), 404/bondho/error page, home, category, product card, chobi, filter, product page, search, policy, SEO ([seo.md](seo.md)) (M3); BFF auth route, `/login`, `/account`, Account link, login page e Turnstile CSP (M4).

## Kivabe kaj kore

1. Shuru: `lib/main.server.dart` nijer shelf server `127.0.0.1:$PORT` e (13.5; `jaspr serve`/build `PORT` dey, local default 8081), `Pipeline` e `securityHeaders(...)`, `cacheControl()`, `bff(...)`, `seoFiles(...)` ([seo.md](seo.md)), tarpor `serveApp` → `renderPage(request, render, settingsCache.get, cfg: config, client: httpClient)` (`lib/services/render.dart`). Env `lib/services/config.dart` → `config` (`Config.fromEnv`): `API_BASE_URL`, `JASPR_INTERNAL_SECRET`, `IMAGE_BASE_URL`, `IMAGE_RESIZE`, `TURNSTILE_SITE_KEY` (10.11 item 2; local e Cloudflare er test key `1x00000000000000000000AA`); bhul hole `FormatException` e variable er naam.
2. Bhasha: `localeOf(path)` (`lib/services/locale.dart`): `/en` ba `/en/...` → `en` ar baki route, na hole `bn`. Browser er `Accept-Language` dekha hoy na (10.3: URL-i bhasha, cache thik thake).
3. API: `apiFor(requestHeaders, locale, config, httpClient)` (`lib/services/api.dart`) protiti request e notun `ApiClient` (shared), ek `http.Client`. Header `apiHeaders`: `X-Shop-Host` = `Host` (API nijei port bad diye normalize kore), Caddy er `X-Real-IP` thakle `X-Client-IP` + `X-Internal-Auth`; local e `X-Real-IP` nai, API connection IP ney.
4. CSS: Tailwind v3.4.19 standalone CLI (`scripts/tailwind.sh`, version ar sha256 pin, binary `website/.dart_tool` e) `tailwind.css` → `web/styles.css`; `tailwind.config.js` e rong, radius, font shudhu CSS variable (9.3). `jaspr_tailwind` Dart 3.13 e resolve hoy na (v1.14).
5. Cache (10.3): `cacheControl()` (`lib/services/cache_control.dart`): `__Host-sid`, `__Host-cart`, `preview` cookie ba response e `Set-Cookie` → `private, no-store` (page er nijer header o bodle, BFF o); baki BFF `/_/...` → `no-store`; baki page nije `Cache-Control` dile seta, na dile 2xx e `public, max-age=60`, onno status e `no-store`.
6. BFF (10.9): `bff(config, httpClient, bffRoutes)` (`lib/services/bff.dart`) shudhu `/_/...` dhore, baki page e jay. POST/PATCH/DELETE e CSRF check: `Origin` thakle hubohu `originOf` (scheme `X-Forwarded-Proto` theke, host:port = `Host`); `Origin` na thakle ba `null` (no-referrer page er form, 10.1) hole `Sec-Fetch-Site: same-origin`; na hole `403 forbidden`. Body Go er `MaxBody` (1 MB) er beshi hole `413 validation_failed` (memory te pora na), bhul UTF-8 ba form encoding `400 validation_failed`. `bffRoutes` (`BffRoute`: method, path regex → Go API path, optional `session`, optional `apiMethod`) e na mille `404 not_found`. Route: `POST /_/auth/otp/send`, `/_/auth/otp/verify`, `/_/auth/logout` → `/api/auth/...`; `PATCH`/`POST /_/account` → `PATCH /api/me` (`POST` account page er JS chhara form, `apiMethod`). Forward: `apiHeaders` (shop, IP), cookie `__Host-sid` → `Authorization: Bearer`, `__Host-cart` → `X-Cart-Key`, `Idempotency-Key`, bhasha nijer page er `Referer` path theke (`localeOf`; nai ba onno host hole `bn`); browser er cookie ar `Accept-Language` jay na. Go API er status, body, `content-type` ar `Retry-After` hubohu. Auth (10.11 item 4): verify `200` e Go er `token` body theke muche `Set-Cookie: __Host-sid=<token>; HttpOnly; Secure; SameSite=Lax; Path=/; Max-Age=2592000` (`_login`); token nai ba `[A-Za-z0-9_-]` chhara okkhor hole `502 internal`, cookie na; verify error hubohu, cookie na. Logout e Go er status jai hok cookie `Max-Age=0` (`_logout`). Cookie set kora uttor `private, no-store`. JS chhara form (`x-www-form-urlencoded`) JSON hoye jay, uttor `303`: 2xx e `Referer` er page e, error e oi page e `?error=<code>` (onno host er Referer ba path `//`/`\` diye hole `/`, open redirect na). API e na pele `502 network_error`, 15 second e `504 timeout`. Baki uttor `no-store`.
7. Settings cache (3.5, 10.10 item 4): `settingsCache.get(host)` (`lib/services/settings_cache.dart` → `SettingsCache`, global `lib/services/api.dart` e; host chhoto harf, port ar sesher `.` chhara, API er moto) `ShopSettings` (settings, version, `translations` bn/en) dey. Prothom bar `version`, `settings`, duita `translations` (ek host e ekshathe ekta load). 30 second por prothom request purono data dey ar background e `version` check (host e ekta); bodlale shob abar. API down ba `429`: purono rakhe, log, 30 second por abar. `shop_not_found`/`shop_suspended`: cache theke bad, porer request error. Faka cache e bhul `get` theke `ApiError` (error page); ochena host cache hoy na.
8. Page (10.10 item 10): `resolvePage(host, path, settingsCache.get)` bhasha (`localeOf`) ar shop er settings niye `Site` (`lib/components/site.dart`, InheritedComponent: `locale`, `settings`, `Translator` (default + override), `catalog` (ei request er `CatalogRepository`: `apiFor` diye `Host`, bhasha, IP), `images` (`ImageUrls`), `t`, `taka` (shop er `bangla_digits`), `href`) banay. Shop nai (`shop_not_found`) → `404`; bondho (`shop_suspended`) → `503` + `Retry-After: 3600` "dokan bondho" page; onno bhul (API down) → log, `503` error page; ei tin page e shop er theme ar layout nai. `locales.enabled` e `en` na thakle `/en/*` → `404` (lekha Bangla). `renderPage` Jaspr `Document` (`lang` = bhasha, viewport `viewport-fit=cover`, `/styles.css`, `<style>` e `themeCss`) render kore status ar header boshay; non-2xx `cacheControl` e `no-store`. Router er 404 ba page er `pageError` (503) er status thake (200 diye dheke na). `StatusPage` `div` (Layout er `<main>` er bhetore).
9. Route ar layout: `App` (`lib/app.dart`, `jaspr_router`) protiti route `/x` ar `/en/x` duitai; na mille `_NotFound` (`setStatusCode(404)`). `Layout` (`lib/components/layout.dart`, 10.5): header (shop er naam → home, desktop e "Category" `/#categories`, `en` chalu thakle bhasha bodlanor link ekoi path e, GET search form `/search?q=`, input 16px), content max 1280px, footer (5 ta policy link `policyKinds`, phone, email, DBID, BFSA thakle), mobile e fixed bottom nav (product page `/p/*` e na, sticky bar; Home, Category, Account; Cart M5 porjonto lukano, 10.10 item 6); header e `md` theke Account link `env(safe-area-inset-bottom)` shoho. Tap 44px (`min-h-11`).
10. Theme (9.3, 9.6): `themeCss` (`lib/services/theme.dart`) `:root` e settings er rong, radius, font, ar shudhu settings er duita font er `@font-face` (`web/fonts/`, bengali/latin subset `unicode-range`, `font-display: swap`). `tailwind.css` er base layer e 9.6 er typography (body 16px/1.7, h1–h3 `clamp`, heading font 500); `tailwind.config.js` e font `var(--font-*)`, fallback `sans-serif`; `text-sm` 14px/1.6.
11. Home (`lib/pages/home.dart`, `AsyncStatelessComponent`, 10.1, 10.5): `categories()` ar featured ekshathe. Announcement (thakle); banner (`settings.banners`, prothom ta LCP; link `safeLink` (`lib/services/link.dart`) diye abar check: `/...` (na `//`, `\`, control char) → bhashar prefix, `https://` + host hubohu, baki link chhara); category `section#categories` (`featured_category_slugs` dile oigulo oi kram e, na hole shob top-level; mobile e side-scroll); featured product: `featured_product_slugs` er prothom 12 ta protiti slug e `product(slug)` ekshathe, `not_found` bad, card er dam variant der sobcheye kom ta (hishab na, Rule 1). API er onno bhul → `pageError` (`lib/pages/status.dart`): `not_found` 404, baki 503 error page + log.
12. Header e `branding.logo_key` thakle logo chobi (`ImageUrls.url` 320, `alt` = naam), na hole naam. Card ar chobi: `ProductCardView` (`lib/components/product_card.dart`): `/p/{slug}` link, chobi, naam, `Price`, stock na thakle "স্টকে নেই". `Price` (`lib/components/price.dart`): `site.taka(price)`, `compare_at_price` thakle kete (`<s>`), `variable_weight` e "/ kg". `ResponsiveImage` (`lib/components/responsive_image.dart`, 10.5 niyom 7): `ImageUrls.url/srcset` (`lib/services/image.dart`: cloudflare e `<base>/cdn-cgi/image/width=W,format=auto/<key>` 320/640/960/1280, `none` e `<base>/<key>`; key er segment encode, `..`/khali segment e `null`), `sizes`, `width`/`height`, LCP e `fetchpriority="high"`, baki `loading="lazy"`; key na thakle `bg-tint` placeholder (`role="img"`, `aria-label`).
13. Category (`lib/pages/category.dart`, `/c/{slug}`): `categories()` (tree e slug khoje naam; na pele 404) ar `products(category, sort, in_stock, min/max, page, limit 24)` ekshathe; list er UI `ProductListing` (`lib/components/product_listing.dart`, search o eta): shironam, koyta, grid, filter, paging. Query `ListQuery.parse` (`lib/services/list_query.dart`): `q` (trim, 100 okkhor), `sort` shudhu 7.2 er 4 ta, `in_stock=1`, `min`/`max` URL e taka (0–1 koti) → API te poisha, `page` 1–10000; bhul value bad (API `400` na). Koyta product `plural('category.count')` (Bangla digit `site.number`). Paging link `withPage` (filter thake, page 1 e `page` na; `rel=prev/next`). Filter: `FilterForm` (`lib/components/filter_sheet.dart`, GET form, JS chhara-o chole; search e `q` lukano input e ar "clear" link e thake) desktop e bame sidebar; mobile e `FilterSheet`: "Filter" button ar `<dialog id="filters">` server e, `@client DialogToggle` (data shudhu dialog id, 10.2) browser e `[data-dialog-open]` → `showModal`, `[data-dialog-close]` → `close`.
14. Local: `make web` (`scripts/web.sh`): `website/.env` load, Tailwind `--watch`, `jaspr serve` (port `pubspec.yaml` er `jaspr.port` 8081). Catalog data: `make dev-seed` (`scripts/dev-seed.sql`, docker er Postgres e `shop_owner` diye; `sobujbazar.localhost` shop lage; 3 category, 5 product, variant, stock batch + movement shoho; abar chalale bad; chobi nai).
15. Product (`lib/pages/product.dart`, `/p/{slug}`, 10.1, 10.5): `product(slug)`; `not_found` → 404 (`pageError`). `Gallery` (`lib/components/gallery.dart`): chobi gulo CSS `scroll-snap` er side-scroll (JS na, `tabindex=0` keyboard e), `ResponsiveImage` (API er `width`/`height`, `alt` = product naam, prothom ta LCP); chobi na thakle placeholder. `review_count > 0` hole "★ rating (count)" (`formatRating`, `plural('product.rating')`). Variant (`lib/components/variant_picker.dart`): shuru te prothom stock e thaka variant (`defaultVariant`); `VariantPrices` protiti variant er dam (`Price`, API er, Rule 1) ar stock na thakle lekha `[data-variant=<id>]` e render kore, bachai chhara baki `hidden`; 2+ variant hole `VariantPicker`: radio `name=variant` (lekha `options` er value, server e), `@client VariantSwitch` (data kichu na) radio bodlale shudhu oi `data-variant` dekhay. JS chhara prothom dam dekha jay. Description `plainText` (`lib/components/plain_text.dart`, 10.10 item 2): `text` e escape, khali line → `<p>`, newline → `<br>`. Mobile e niche fixed sticky bar (variant naam + dam, `md:hidden`); "Cart e add" M5 e.
16. Search (`lib/pages/search.dart`, `/search?q=`): `noindex` (`SeoHead`, [seo.md](seo.md)); `q` 2 okkhorer kom hole API call na (API search kore na, 6.4), "likhun" lekha; na hole `products(q:, filter...)` → `ProductListing` (shironam `search.title`, khali hole `search.empty`). Policy (`lib/pages/policy.dart`, `/policy/{kind}`, v1.13): route shudhu `policyKinds` er 5 ta (baki router er 404); `catalog.policy(kind)` (API: shop er lekha, na hole Bangla placeholder) → `plainText`; API `not_found` 404.
17. Security header (`lib/services/security_headers.dart`, 12.2, 10.10 item 7): `securityHeaders(config.imageBaseUrl)` middleware (`main.server.dart` e shobar baire) protiti response e `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `X-Frame-Options: DENY` (dart:io er `SAMEORIGIN` er bodole), CSP `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' <chobir origin> data:; font-src 'self'; connect-src 'self'; base-uri 'none'; form-action 'self'; frame-ancestors 'none'`. Inline script nai (Jaspr client `<script src>`); `@client` shudhu `DialogToggle`, `LoginForm` ar `VariantSwitch` (`client_components_test.dart` list dhore). `/login` ar `/en/login` e (10.11 item 3) `script-src 'self' https://challenges.cloudflare.com` ar `frame-src https://challenges.cloudflare.com` (Turnstile); baki page e frame-src nai (`default-src 'self'`).
18. Login (`lib/pages/login.dart`, `/login`, 10.11 item 1): `noindex`; `<head>` e Turnstile `api.js` (`async defer`). Server e duita form: `#login-phone` (`purpose=login` lukano, phone `type=tel inputmode=numeric autocomplete=tel`, `.cf-turnstile` `data-sitekey` = `TURNSTILE_SITE_KEY`, `data-response-field-name=turnstile_token`, `data-language` = bhasha) ar `#login-code` (`hidden`; code `inputmode=numeric autocomplete=one-time-code`, "number bodlan" button). Error er lekha server e lukano `[data-error=<code>]` e (send/verify er code); `?error=<code>` (JS chhara submit er BFF `303`) `#login-error` e dekhay (`site.error`: ochena code → `error.internal`). `<noscript>` e "JS chalu korun" (Turnstile JS chhara chole na). `@client LoginForm` (`lib/components/login_form.dart`, data shudhu `next`): phone form submit → `ApiClient(Uri.base)` diye BFF `/_/auth/otp/send` (`{phone, purpose, turnstile_token}`), thik hole code form, phone shudhu memory te; protiti send er por `turnstile.reset()` (token ekbar); code submit → `/_/auth/otp/verify` (`{phone, code}`) → `location.assign(next)`; bhul hole `[data-error]` er lekha, `otp_too_many_attempts` e abar phone form. `next` = `safeNext(query['next'], '/account')`: shudhu `/` diye shuru, `//`, `\`, control okkhor na (open redirect na).
19. Account (`lib/pages/account.dart`, `/account`, 10.11 item 5): `__Host-sid` cookie nai → `303 /login?next=/account` (bhasha prefix shoho), API call na; thakle `ApiClient(..., token:)` (`site.catalog.api` er base/header) diye `AccountRepository.me()` (`GET /api/me`, Bearer); `401` (expire/revoke) hole o `303 /login?next=`; onno bhul `pageError`. Page `noindex`: phone, JS chhara form `POST /_/account` (naam `autocomplete=name` max 100, SMS er bhasha `select` bn/en) → BFF `PATCH /api/me` → `303` ei page e (bhul hole `?error=<code>` `role=alert` e), logout form `POST /_/auth/logout` (cookie muche, `303` ei page e, tarpor `/login` e). Cookie thake, tai `cacheControl` `private, no-store`.

## Bhul hole ki hoy

- Env nai ba bhul: prothom `config` use e `FormatException` (variable er naam shoho).
- `Host` nai: `X-Shop-Host` khali, API `404 shop_not_found` → 404 page.
- API down ar cache faka: `503` error page (`no-store`), log `page: ...`; cache e purono thakle purono dekhay.
- Router e route nai: `404` page (layout shoho).
- Turnstile script na ele (network, CSP): widget token nai, Go `400 turnstile_failed`, `#login-error` e lekha. JS bondho: `<noscript>` lekha; form submit e BFF `303 /login?error=turnstile_failed`.
- `/account` e session expire: `303 /login?next=/account`; login er por abar `/account`.
- BFF: CSRF check fail `403 forbidden`; verify e Go er uttor e thik token nai `502 internal`; ochena `/_/` route `404 not_found`; API down `502 network_error`, dhir `504 timeout` (client `ApiError` er code er moto).

## Bodlanor age mone rakho

- `X-Real-IP` shudhu Caddy dey: tai server shudhu loopback e (`main.server.dart`); Jaspr er default `runApp` `0.0.0.0` e bind kore, oita use koro na.
- BFF e notun route `bffRoutes` e ar test; Go er `Set-Cookie` forward hoy na, cookie shudhu route er `session` theke.
- Notun personal cookie (jemon M4/M5 e) hole `_personal` e jog ar test.
- `Document(base: null)` (`render.dart`): `<base>` CSP `base-uri 'none'` e atke, tokhon client script relative path e `/c/...`, `/p/...` page e 404 hoy ar hydration (filter dialog, variant) chole na; base na thakle Jaspr `/main.client.dart.js` dey.
- Jaspr update hole `jaspr install-skills --agent claude-code` abar ar `*.options.dart` (`dart run build_runner build`).
- `__Host-sid` e `Secure` ar `__Host-` prefix: browser shudhu https e rakhe, tai local `make web` (http) e login er cookie thake na (Chromium `InvalidPrefix`); browser e login dekhte local https proxy lage (16.1 v1.23 er proshno, M7 er age).

## Proshno-uttor

- **Login form keno JS chhara chole na?** Turnstile nijei JS chhara token dey na; phone rakhar notun cookie ba URL query (log, referrer e phone) na (10.11 item 1).
- **Account form keno POST, BFF e PATCH?** JS chhara HTML form shudhu GET/POST pare; `@client` barano lage na (10.2), BFF `apiMethod: 'PATCH'` e Go te pathay.

- **Admin publish korle website e kokhon?** Max ~30 second + ek request: TTL er por prothom request purono dey ar refresh shuru kore, porer request notun pay (3.5: 1 minute er moddhe).
- **Translation override save (M8) e version bare na hole?** Purono lekha porer publish porjonto; tai M8 e override save e `version` barabe (3.5 item 6).

- **Browser er bhasha keno dekhi na?** Ekoi URL e alada HTML hole Cloudflare cache bhul bhashar page dite pare (10.3); bhasha bodlano shudhu link diye.
- **Logout JS chhara form keno?** Account page e `@client` lage na (10.2); BFF form e `303` dey ar cookie muche, tarpor `/account` nijei `/login` e pathay.
- **`GET /api/me` BFF e nai keno?** `/account` SSR e cookie er token diye sora-sori Go te jay (`ApiClient(token:)`); browser er JS e profile lage na.
- **Account link login na thakleo keno?** Page `public, max-age=60` cache hoy, tai header e login obostha dekhano jay na; link `/account` e, session na thakle `/login` e.
- **Login form markup server e, `LoginForm` shudhu kaj keno?** Client bundle choto, lekha ar error message server er translator theke; client e data shudhu `next`.
