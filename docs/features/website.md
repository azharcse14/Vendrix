# Website (Jaspr)

Design: 10.1–10.5, 10.9, 10.10, 10.11, 10.12, 3.2, 13.5 · Milestone: M3, M4, M5 · Code: `website/`

## Ki kore

Customer er website: Jaspr server mode e protiti page server e render hoy (SSR), dokan chena jay `Host` theke. Bangla root e, English `/en/...` e. Browser kokhono Go API te jay na; page er data Jaspr server API theke ane.
Ache: config, request theke API client, `Cache-Control`, BFF, settings cache, theme/font, layout (header, bottom nav, footer), 404/bondho/error page, home, category, product card, chobi, filter, product page, search, policy, SEO ([seo.md](seo.md)) (M3); BFF auth route, `/login`, `/account`, Account link, login page e Turnstile CSP (M4); BFF cart ar wishlist route, verify e cart/`wl` cookie, `/cart`, cart e add, Cart link + badge, heart (`wl`), `/account/wishlist`, login e `cart_notices` (M5); BFF checkout ar order route, token page `private, no-store` (M6 step 12).

## Kivabe kaj kore

1. Shuru: `lib/main.server.dart` nijer shelf server `127.0.0.1:$PORT` e (13.5; `jaspr serve`/build `PORT` dey, local default 8081), `Pipeline` e `securityHeaders(...)`, `cacheControl()`, `bff(...)`, `seoFiles(...)` ([seo.md](seo.md)), tarpor `serveApp` → `renderPage(request, render, settingsCache.get, cfg: config, client: httpClient)` (`lib/services/render.dart`). Env `lib/services/config.dart` → `config` (`Config.fromEnv`): `API_BASE_URL`, `JASPR_INTERNAL_SECRET`, `IMAGE_BASE_URL`, `IMAGE_RESIZE`, `TURNSTILE_SITE_KEY` (10.11 item 2; local e Cloudflare er test key `1x00000000000000000000AA`); bhul hole `FormatException` e variable er naam.
2. Bhasha: `localeOf(path)` (`lib/services/locale.dart`): `/en` ba `/en/...` → `en` ar baki route, na hole `bn`. Browser er `Accept-Language` dekha hoy na (10.3: URL-i bhasha, cache thik thake).
3. API: `apiFor(requestHeaders, locale, config, httpClient)` (`lib/services/api.dart`) protiti request e notun `ApiClient` (shared), ek `http.Client`. Header `apiHeaders`: `X-Shop-Host` = `Host` (API nijei port bad diye normalize kore), Caddy er `X-Real-IP` thakle `X-Client-IP` + `X-Internal-Auth`; local e `X-Real-IP` nai, API connection IP ney.
4. CSS: Tailwind v3.4.19 standalone CLI (`scripts/tailwind.sh`, version ar sha256 pin, binary `website/.dart_tool` e) `tailwind.css` → `web/styles.css`; `tailwind.config.js` e rong, radius, font shudhu CSS variable (9.3). `jaspr_tailwind` Dart 3.13 e resolve hoy na (v1.14).
5. Cache (10.3): `cacheControl()` (`lib/services/cache_control.dart`): `__Host-sid`, `__Host-cart`, `preview` cookie ba response e `Set-Cookie` → `private, no-store` (page er nijer header o bodle, BFF o); token page (`/order/`, `/confirm/`, `/invoice/`, `/print/`, `/en/` shoho, 10.1) cookie chhara-o `private, no-store`; baki BFF `/_/...` → `no-store`; baki page nije `Cache-Control` dile seta, na dile 2xx e `public, max-age=60`, onno status e `no-store`.
6. BFF (10.9): `bff(config, httpClient, bffRoutes)` (`lib/services/bff.dart`) shudhu `/_/...` dhore, baki page e jay. POST/PATCH/DELETE e CSRF check: `Origin` thakle hubohu `originOf` (scheme `X-Forwarded-Proto` theke, host:port = `Host`); `Origin` na thakle ba `null` (no-referrer page er form, 10.1) hole `Sec-Fetch-Site: same-origin`; na hole `403 forbidden`. Body Go er `MaxBody` (1 MB) er beshi hole `413 validation_failed` (memory te pora na), bhul UTF-8 ba form encoding `400 validation_failed`. `bffRoutes` (`BffRoute`: method, path regex → Go API path, optional `session`, `apiMethod`, `ints`, `formDone`) e na mille `404 not_found`. Route: `POST /_/auth/otp/send`, `/_/auth/otp/verify`, `/_/auth/logout` → `/api/auth/...`; `PATCH`/`POST /_/account` → `PATCH /api/me` (`POST` account page er JS chhara form, `apiMethod`). Forward: `apiHeaders` (shop, IP), cookie `__Host-sid` (shudhu `[A-Za-z0-9_-]`, `validSid`; khali ba bhul hole guest) → `Authorization: Bearer`, `__Host-cart` → `X-Cart-Key` (shudhu Go er format `^[A-Z2-7]{26}$` hole, ar `__Host-sid` na thakle; verify e sid thakleo jay, merge er jonno), `Idempotency-Key`, bhasha nijer page er `Referer` path theke (`localeOf`; nai ba onno host hole `bn`); browser er cookie ar `Accept-Language` jay na. Go API er status, body, `content-type` ar `Retry-After` hubohu. Auth (10.11 item 4): verify `200` e Go er `token` body theke muche `Set-Cookie: __Host-sid=<token>; HttpOnly; Secure; SameSite=Lax; Path=/; Max-Age=2592000` (`_login`); token nai ba `[A-Za-z0-9_-]` chhara okkhor hole `502 internal`, cookie na; verify error hubohu, cookie na. Logout e Go er status jai hok cookie `Max-Age=0` (`_logout`). Cart (10.12 item 1, `_cart`): `POST /_/cart/items`, `PATCH`/`DELETE /_/cart/items/{id}`, JS chhara form er `POST /_/cart/items/{id}` (→ `PATCH`) ar `POST /_/cart/items/{id}/delete` (→ `DELETE`); 2xx e Go er `cart_key` body theke muche `__Host-cart=<key>; HttpOnly; Secure; SameSite=Lax; Path=/; Max-Age=2592000`, `cart_key` na thakle guest er ager valid key abar set (sliding 30 din); valid `__Host-sid` thakle `cart_key` muche kintu cookie na (10.12 item 8); bhul format er `cart_key` `502`; Go error e cookie na. Form er `variant_id`, `quantity` JSON e number (`ints`), 2xx e `303 /cart` (`/en/...` Referer e `/en/cart`, `formDone`). Wishlist: `POST`/`DELETE /_/wishlist/{id}` → `/api/wishlist/{id}` (login e; guest er `wl` JS lekhe). Checkout ar order (10.9, 10.13): `POST /_/checkout/quote` → `/api/checkout/quote`, `POST /_/checkout` → `POST /api/orders` (browser er `Idempotency-Key` header forward), `POST /_/orders/{token}/cancel` → `/api/orders/{token}/cancel`, `POST /_/confirm/{token}` → `/api/confirm/{token}`, `POST /_/track` → `/api/orders/track`; token shudhu `[A-Za-z0-9_-]` (na hole `404`, Go er onno path e jawa jay na); `session` na (cookie set na), body ar Go er status/JSON (`409 otp_required`/`price_changed` er `details`, `422 idempotency_key_reused`, `429` + `Retry-After`) hubohu; GET route nai (zone, `/account/orders` page SSR e Go theke). Verify `200` e (10.12 item 2, 3) `__Host-cart` thakle `Max-Age=0`; `wl` thakle (koma diye decimal, valid ID, prothom 50) notun token diye `WishlistRepository.merge` (`POST /api/wishlist/merge`), shofol hole (ba valid ID nai) `wl=; Path=/; Secure; SameSite=Lax; Max-Age=0`, fail hole log ar `wl` thake (login thik, porer login e abar); body te `cart_notices` thake. Cookie set kora uttor `private, no-store` (ek uttor e onek `Set-Cookie`). JS chhara form (`x-www-form-urlencoded`) JSON hoye jay, uttor `303`: 2xx e `Referer` er page e, `401` e `/login?next=<Referer er path>` (bhasha prefix shoho), baki error e oi page e `?error=<code>` (onno host er Referer ba path `//`/`\` diye hole `/`, open redirect na). Session expire (10.12 item 7): valid `__Host-sid` pathiye Go `401` dile (JSON ba form) uttor e `__Host-sid` `Max-Age=0` (logout e already thakle duibar na). API e na pele `502 network_error`, 15 second e `504 timeout`. Baki uttor `no-store`.

## Bhul hole ki hoy

- Env nai ba bhul: prothom `config` use e `FormatException` (variable er naam shoho).
- `Host` nai: `X-Shop-Host` khali, API `404 shop_not_found` → 404 page.
- API down ar cache faka: `503` error page (`no-store`), log `page: ...`; cache e purono thakle purono dekhay.
- Router e route nai: `404` page (layout shoho).
- Turnstile script na ele (network, CSP): widget token nai, Go `400 turnstile_failed`, `#login-error` e lekha. JS bondho: `<noscript>` lekha; form submit e BFF `303 /login?error=turnstile_failed`.
- `/account` e session expire: `303 /login?next=/account`; login er por abar `/account`.
- `/cart` e API down: `503` error page; badge e bhul hole badge chupchap khali. Product page e wishlist GET bhul: heart off. `AddToCart` er bhul: `#cart-add-error` e lekha (ochena code `internal`). Guest heart e `wl` 50 er beshi: purono ta bad.
- BFF: CSRF check fail `403 forbidden`; verify e Go er uttor e thik token nai ba cart e bhul `cart_key` `502 internal`; verify er por wishlist merge fail: log `wishlist merge: ...`, login thik, `wl` thake; ochena `/_/` route `404 not_found`; API down `502 network_error`, dhir `504 timeout` (client `ApiError` er code er moto).

## Bodlanor age mone rakho

- `X-Real-IP` shudhu Caddy dey: tai server shudhu loopback e (`main.server.dart`); Jaspr er default `runApp` `0.0.0.0` e bind kore, oita use koro na.
- BFF e notun route `bffRoutes` e ar test; Go er `Set-Cookie` forward hoy na, cookie shudhu route er `session` theke.
- Notun personal cookie (jemon M4/M5 e) hole `_personal` e jog ar test.
- `Document(base: null)` (`render.dart`): `<base>` CSP `base-uri 'none'` e atke, tokhon client script relative path e `/c/...`, `/p/...` page e 404 hoy ar hydration (filter dialog, variant) chole na; base na thakle Jaspr `/main.client.dart.js` dey.
- Cookie shob jaygay `parseCookies` (`bff.dart`; page e `requestCookies`) diye; Jaspr er `context.cookies` na: oita `dart:io` `Cookie` e pore, `wl` er koma te `FormatException` dey ar puro page bhange (`cart_test.dart` er `wl` koma case).
- Jaspr update hole `jaspr install-skills --agent claude-code` abar ar `*.options.dart` (`dart run build_runner build`).
- `__Host-sid` e `Secure` ar `__Host-` prefix: browser shudhu https e rakhe, tai local `make web` (http) e login er cookie thake na (Chromium `InvalidPrefix`); browser e login `make https` diye `https://sobujbazar.localhost:8443` e (Caddy `tls internal`, 13.1 v1.27). ## Proshno-uttor

- **Login form keno JS chhara chole na?** Turnstile nijei JS chhara token dey na; phone rakhar notun cookie ba URL query (log, referrer e phone) na (10.11 item 1).
- **Account form keno POST, BFF e PATCH?** JS chhara HTML form shudhu GET/POST pare; `@client` barano lage na (10.2), BFF `apiMethod: 'PATCH'` e Go te pathay.

- **Admin publish korle website e kokhon?** Max ~30 second + ek request: TTL er por prothom request purono dey ar refresh shuru kore, porer request notun pay (3.5: 1 minute er moddhe).
- **Translation override save (M8) e version bare na hole?** Purono lekha porer publish porjonto; tai M8 e override save e `version` barabe (3.5 item 6).

- **Browser er bhasha keno dekhi na?** Ekoi URL e alada HTML hole Cloudflare cache bhul bhashar page dite pare (10.3); bhasha bodlano shudhu link diye.
- **Cart page e keno `@client` nai?** Total kokhono client e na (Rule 1), JS kom, Facebook in-app browser e form nirbhorjoggo (10.12 item 4); qty/bad form `303` e page abar render.
- **Badge keno `GET /api/cart/count`, `GET /api/cart` na?** `GET /api/cart` normalize kore notice ekbar dey (8.4); product page er badge dakle `item_removed` oikhane harato. Tai badge halka count (normalize na), notice shudhu `/cart` e (v1.31, user).
- **Session expire hole?** Go `401` e website `/login?next=<page>` e pathay ar `__Host-sid` muche (`toLogin`, BFF, `loginHref`); na hole expire cookie protiti page e `401` khay. Badge shudhu lukay (protiti page redirect bhalo na) (10.12 item 7).
- **Heart keno JS chhara lukano?** Guest e cookie JS lekhe (server `wl` dekhe na, page cache), tai JS chhara kaj kore na; ordhek kaj kora button dekhano hoy na.
- **`wl` keno `_personal` e nai?** Server `wl` diye kichu render kore na (guest er heart JS e), tai product page public cache thake (10.12 item 3); cart ar login er cookie `_personal` e.
- **Login thakle `X-Cart-Key` keno jay na?** Go Bearer thakle key dekhe na (7.4); verify e jay, karon guest cart merge oi key diye (purono sid cookie thakleo).
- **Cookie chhara `/cart` keno `public, max-age=60`?** Cookie nai mane cart nai: page khali, personal kichu na, sob guest er ekoi HTML (10.3 er niyom); `__Host-cart` ba `__Host-sid` thakle `private, no-store`.
- **Guest heart e 50 er beshi hole?** `wlCookie` shesh 50 rakhe, purono ta bad (cookie choto, Go merge o 50 ID ney; error dekhano hoy na).
- **`wl` merge fail hole cookie muche na keno?** Muchle guest er heart hariye jeto; login thik thake, porer login e abar merge (Go te `ON CONFLICT`, duibar e khoti na).
- **Logout JS chhara form keno?** Account page e `@client` lage na (10.2); BFF form e `303` dey ar cookie muche, tarpor `/account` nijei `/login` e pathay.
- **`GET /api/me` BFF e nai keno?** `/account` SSR e cookie er token diye sora-sori Go te jay (`ApiClient(token:)`); browser er JS e profile lage na.
- **Account link login na thakleo keno?** Page `public, max-age=60` cache hoy, tai header e login obostha dekhano jay na; link `/account` e, session na thakle `/login` e.
- **Login form markup server e, `LoginForm` shudhu kaj keno?** Client bundle choto, lekha ar error message server er translator theke; client e data shudhu `next`.
