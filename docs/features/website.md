# Website (Jaspr)

Design: 10.1–10.5, 10.9, 10.10, 10.11, 10.12, 3.2, 13.5 · Milestone: M3, M4, M5, M6, MU · Code: `website/` (page er UI: [website-pages.md](website-pages.md))

## Ki kore

Customer er website: Jaspr server mode e protiti page server e render hoy (SSR), dokan chena jay `Host` theke. Bangla root e, English `/en/...` e. Browser kokhono Go API te jay na; page er data Jaspr server API theke ane.
Ache: config, request theke API client, `Cache-Control`, BFF, settings cache, theme/font, layout (header, bottom nav, footer), 404/bondho/error page, home, category, product card, chobi, filter, product page, search, policy, SEO ([seo.md](seo.md)) (M3); BFF auth route, `/login`, `/account`, Account link, login page e Turnstile CSP (M4); BFF cart ar wishlist route, verify e cart/`wl` cookie, `/cart`, cart e add, Cart link + badge, heart (`wl`), `/account/wishlist`, login e `cart_notices` (M5); BFF checkout ar order route, `/checkout` + `@client CheckoutForm`, `/order/{token}` (+ `/done`), `/confirm/{token}`, `/track` (SSR POST), `/account/orders`, token page header, `/checkout` e Turnstile CSP (M6); UI pass: component class, icon, page restyle (MU).

5. Cache (10.3): `cacheControl()` (`lib/services/cache_control.dart`): `__Host-sid`, `__Host-cart`, `preview` cookie ba response e `Set-Cookie` → `private, no-store` (page er nijer header o bodle, BFF o); token page (`/order/`, `/confirm/`, `/invoice/`, `/print/`, `/en/` shoho, 10.1), `/track`, `/cart` ar `/checkout` (v1.36) cookie chhara-o `private, no-store`; baki BFF `/_/...` → `no-store`; baki page nije `Cache-Control` dile seta, na dile 2xx e `public, max-age=60`, onno status e `no-store`.
6. BFF (10.9): `bff(config, httpClient, bffRoutes)` (`lib/services/bff.dart`) shudhu `/_/...` dhore, baki page e jay. POST/PATCH/DELETE e CSRF check: `Origin` thakle hubohu `originOf` (scheme `X-Forwarded-Proto` theke, host:port = `Host`); `Origin` na thakle ba `null` (no-referrer page er form, 10.1) hole `Sec-Fetch-Site: same-origin`; na hole `403 forbidden`. Body 1 MB (`MaxBody`) er beshi `413`, bhul UTF-8/form encoding `400` (`validation_failed`). `bffRoutes` (`BffRoute`: method, path regex → Go API path, optional `session`, `apiMethod`, `ints`, `formDone`) e na mille `404 not_found`. Route: `POST /_/auth/otp/send`, `/_/auth/otp/verify`, `/_/auth/logout` → `/api/auth/...`; `PATCH`/`POST /_/account` → `PATCH /api/me` (`POST` account page er JS chhara form, `apiMethod`). Forward: `apiHeaders` (shop, IP), cookie `__Host-sid` (shudhu `[A-Za-z0-9_-]`, `validSid`; khali ba bhul hole guest) → `Authorization: Bearer`, `__Host-cart` → `X-Cart-Key` (shudhu Go er format `^[A-Z2-7]{26}$` hole, ar `__Host-sid` na thakle; verify e sid thakleo jay, merge er jonno), `Idempotency-Key`, bhasha `Referer` path theke (`localeOf`; nai ba onno host e `bn`); browser er cookie/`Accept-Language` na. Go er status, body, `content-type`, `Retry-After` hubohu. Auth (10.11 item 4): verify `200` e Go er `token` body theke muche `Set-Cookie: __Host-sid=<token>; HttpOnly; Secure; SameSite=Lax; Path=/; Max-Age=2592000` (`_login`); token nai ba bhul okkhor e `502 internal`; error e cookie na. Logout e Go er status jai hok cookie `Max-Age=0` (`_logout`). Cart (10.12 item 1, `_cart`): `POST /_/cart/items`, `PATCH`/`DELETE /_/cart/items/{id}`, JS chhara form er `POST /_/cart/items/{id}` (→ `PATCH`) ar `POST /_/cart/items/{id}/delete` (→ `DELETE`); 2xx e Go er `cart_key` body theke muche `__Host-cart=<key>; HttpOnly; Secure; SameSite=Lax; Path=/; Max-Age=2592000`, `cart_key` na thakle ager valid key abar set (sliding 30 din); valid `__Host-sid` thakle `cart_key` muche kintu cookie na (10.12 item 8); bhul format er `cart_key` `502`; Go error e cookie na. Form er `variant_id`, `quantity` JSON e number (`ints`), 2xx e `303 /cart` (`/en` e `/en/cart`, `formDone`). Wishlist: `POST`/`DELETE /_/wishlist/{id}` → `/api/wishlist/{id}` (login e; guest er `wl` JS lekhe). Checkout ar order (10.9, 10.13): `POST /_/checkout/quote` → `/api/checkout/quote`, `POST /_/checkout` → `POST /api/orders` (browser er `Idempotency-Key` header forward), `POST /_/orders/{token}/cancel` → `/api/orders/{token}/cancel`, `POST /_/confirm/{token}` → `/api/confirm/{token}` (`/_/track` nai: `/track` nijer page e SSR POST, item 25); cancel ar confirm route e `page` (`/order/{token}`, `/confirm/{token}`): token page `no-referrer`, tai JS chhara form er `303` (ar error e `?error=`) oi page e, bhasha form er `?lang=en` theke (Referer na, 10.13 item 7); token shudhu `[A-Za-z0-9_-]` (na hole `404`, Go er onno path e jawa jay na); `session` na (cookie set na), body ar Go er status/JSON (`409 otp_required`/`price_changed` er `details`, `422 idempotency_key_reused`, `429` + `Retry-After`) hubohu; GET route nai (zone, `/account/orders` page SSR e Go theke). Verify `200` e (10.12 item 2, 3) `__Host-cart` thakle `Max-Age=0`; `wl` thakle (koma diye decimal, valid ID, prothom 50) notun token diye `WishlistRepository.merge` (`POST /api/wishlist/merge`), shofol (ba valid ID nai) hole `wl` `Max-Age=0`, fail e log ar `wl` thake (porer login e abar); body te `cart_notices` thake. Cookie set kora uttor `private, no-store`. JS chhara form (`x-www-form-urlencoded`) JSON hoye jay, uttor `303`: 2xx e `Referer` er page e, `401` e `/login?next=<Referer er path>` (bhasha prefix shoho), baki error e oi page e `?error=<code>` (onno host ba `//`/`\` path e `/`, open redirect na). Session expire (10.12 item 7): valid `__Host-sid` pathiye Go `401` dile (JSON ba form) uttor e `__Host-sid` `Max-Age=0` (logout e already thakle duibar na). API e na pele `502 network_error`, 15 second e `504 timeout`; baki uttor `no-store`.
7. Settings cache (3.5, 10.10 item 4): `settingsCache.get(host)` (`lib/services/settings_cache.dart` → `SettingsCache`, global `lib/services/api.dart` e; host chhoto harf, port ar sesher `.` chhara, API er moto) `ShopSettings` (settings, version, `translations` bn/en) dey. ## Bhul hole ki hoy

- Env nai ba bhul: prothom `config` use e `FormatException` (variable er naam shoho).
- `Host` nai: `X-Shop-Host` khali, API `404 shop_not_found` → 404 page.
- API down ar cache faka: `503` error page (`no-store`), log `page: ...`; cache e purono thakle purono dekhay.
- Router e route nai: `404` page (layout shoho).
- `/checkout` e OTP box khola, code khali ba 6 digit na: client submit kore na (`otp_required` er lekha, field `aria-invalid`). Na hole Go Turnstile chaito (token already use), `turnstile_failed`.
- Turnstile script na ele (network, CSP): widget token nai, Go `400 turnstile_failed`, `#login-error` e lekha. JS bondho: `<noscript>` lekha; form submit e BFF `303 /login?error=turnstile_failed`.
- `/account` e session expire: `303 /login?next=/account`; login er por abar `/account`.
- `/cart` e API down: `503` error page; badge e bhul hole badge chupchap khali. Product page e wishlist GET bhul: heart off. `AddToCart` er bhul: `#cart-add-error` e lekha (ochena code `internal`). Guest heart e `wl` 50 er beshi: purono ta bad.
- BFF: CSRF check fail `403 forbidden`; verify e Go er uttor e thik token nai ba cart e bhul `cart_key` `502 internal`; verify er por wishlist merge fail: log `wishlist merge: ...`, login thik, `wl` thake; ochena `/_/` route `404 not_found`; API down `502 network_error`, dhir `504 timeout` (client `ApiError` er code er moto).

## Proshno-uttor

- **Admin publish korle website e kokhon?** Max ~30 second + ek request: TTL er por prothom request purono dey ar refresh shuru kore, porer request notun pay (3.5: 1 minute er moddhe).
- **Translation override save (M8) e version bare na hole?** Purono lekha porer publish porjonto; tai M8 e override save e `version` barabe (3.5 item 6).
- **Browser er bhasha keno dekhi na?** Ekoi URL e alada HTML hole Cloudflare cache bhul bhashar page dite pare (10.3); bhasha bodlano shudhu link diye.
- **Badge keno `GET /api/cart/count`, `GET /api/cart` na?** `GET /api/cart` normalize kore notice ekbar dey (8.4); product page er badge dakle `item_removed` oikhane harato. Tai badge halka count, notice shudhu `/cart` e.
- **Session expire hole?** Go `401` e website `/login?next=<page>` e pathay ar `__Host-sid` muche (`toLogin`, BFF, `loginHref`); na hole expire cookie protiti page e `401` khay. Badge shudhu lukay (protiti page redirect bhalo na) (10.12 item 7).
- **`wl` keno `_personal` e nai?** Server `wl` diye kichu render kore na (guest er heart JS e), tai product page public cache thake (10.12 item 3); cart ar login er cookie `_personal` e.
- **Login thakle `X-Cart-Key` keno jay na?** Go Bearer thakle key dekhe na (7.4); verify e jay, karon guest cart merge oi key diye (purono sid cookie thakleo).
- **Cookie chhara `/cart` keno `private, no-store`?** Guest khali `/cart` cache hole product add (notun `__Host-cart`) er por browser cache theke khali cart dekhay, checkout e jaoa jay na (10.3).
- **Guest heart e 50 er beshi hole?** `wlCookie` shesh 50 rakhe, purono ta bad (cookie choto, Go merge o 50 ID ney; error dekhano hoy na).
- **`wl` merge fail hole cookie muche na keno?** Muchle guest er heart hariye jeto; login thik thake, porer login e abar merge (Go te `ON CONFLICT`, duibar e khoti na).
- **`GET /api/me` BFF e nai keno?** `/account` SSR e cookie er token diye sora-sori Go te jay (`ApiClient(token:)`); browser er JS e profile lage na.
