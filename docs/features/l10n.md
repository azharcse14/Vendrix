# Bhasha, taka ar tarikh (shared)

Design: 9.8, 4.3, 2.3 · Milestone: M2 · Code: `packages/shared/lib/format`, `packages/shared/lib/l10n`, `packages/shared/lib/models`

## Ki kore

UI lekha (button, error) developer er default (`bn.dart`, `en.dart`) ar admin er override theke ashe; English na thakle Bangla. Content (`{"bn","en"}`) `LocalizedText` diye.
Website, admin ar app ekoi niyome taka dekhay: `৳১,২৫,০০০` (Bangla) ba `৳1,25,000` (English digit), lakh-style comma, ৳ samne, poisha thakle duita doshomik. Tarikh shop er timezone e: "২৭ অক্টোবর ২০২৬". Database e taka shob shomoy integer poisha, shomoy UTC.

## Kivabe kaj kore

0. `Translator(locale, overrides:, onMissing:)` (`l10n/translator.dart`): `t(key, args)` khoje `override[locale]` → `defaultMessages[locale]` → `override[bn]` → `defaultMessages[bn]` → key nijei (`onMissing` dake); `{name}` er jaygay `args`. `plural(key, count, args)`: English e `key.one`/`key.other`, Bangla e `.other`; `.one` kothao na pele `.other` (Bangla fallback); `{count}` e `args['count']` (jemon Bangla digit er lekha) thakle seta, na hole count. Default lekha `l10n/bn.dart`, `en.dart` (`const Map`, v1.12); `error.<code>` Go er `httpx/message.go` er protiti code ar client er `network_error`, `timeout`. `LocalizedText.of(locale)` (`models/localized_text.dart`): `values[locale]`, khali hole `bn`.
1. `numberLocale(uiLocale, banglaDigits:)` (`format/money.dart`): UI bhasha `bn` ar shop er `locales.bangla_digits` on hole `bn`, na hole `en_IN` (v1.12).
2. `formatTaka(poisha, locale)`: taka (`poisha ~/ 100`) `NumberFormat('#,##,##0', locale)`, poisha thakle locale er doshomik chinho ar `NumberFormat('00')` (shob int, double na); samne ৳, minus hole `-৳` (v1.12). `NumberFormat.currency` na (tar `bn` pattern e ৳ pichone, shob shomoy doshomik). `formatCount(n, locale)`: shonkhya (page, koyta product) ekoi pattern e, ৳ chhara. `formatRating(r, locale)`: rating `NumberFormat('0.0')` (`৪.৫`).
3. `formatDate(t, uiLocale:, banglaDigits:, timeZone:)` (`format/date.dart`): `t` UTC kore shop er offset (`_offsets`, ekhon `Asia/Dhaka` +6) jog, `DateFormat('d MMMM y')` mash er naam UI bhasha theke, `useNativeDigits` `numberLocale` theke; ochena timezone e `ArgumentError` (Rule 5, v1.12).

Website e (M3, [website.md](website.md)): bhasha URL theke (`localeOf`: `/en/...` → `en`, baki `bn`; `localePath`), `Site` e `Translator(locale, overrides: shop er /api/translations)` (settings cache e), taka/shonkhya/rating `Site.taka`, `number`, `rating` (`numberLocale` shop er `bangla_digits` diye). Website er UI key: `nav.*`, `search.*`, `page.*`, `footer.*`, `home.*`, `product.*`, `category.*`, `policy.*` (`l10n/bn.dart`, `en.dart`; `messages_test` duitay ekoi key dhore).

## Bhul hole ki hoy

- Ochena locale `intl` er `ArgumentError` dey; caller `numberLocale` er output-i dibe.
- Ochena `timeZone`: `ArgumentError` (onno deshe shop MT e).

## Bodlanor age mone rakho

- Go te notun error code (`httpx/message.go`) jog korle `bn.dart`, `en.dart` e `error.<code>`; `messages_test.dart` Go file pore dhore.
- Notun key duita file ei jog koro (test ekoi key chay).
- Notun timezone lagle `_offsets` e DST thakle choto map cholbe na; `package:timezone` (2.3 bodol).
- `intl` update e `bn` er digit ba pattern bodlale `money_test.dart` dhorbe.
- Display shob `int` e; hishab kokhono ekhane na, Go er `pricing` e (Rule 1).
- `formatDate` `date_symbol_data_local` diye shob locale er tarikh data ane; web bundle boro lagle (M7) shudhu `bn`/`en` er data.
