## Open question (uttor: shob recommendation, design v1.10)

1. **M4 er age admin API kivabe chole?** (3.2, 4.2, 7.7, 15). Admin CRUD M1 e, kintu staff session (`httpx.StaffSession`, login) M4 e.
   Options: (a) M1 e admin route register, `RequireStaff` fail-closed (staff context na thakle shob shomoy `401 unauthenticated`); test e `httpx.WithStaff(ctx, ...)` diye context boshano; M4 er session middleware ei context-i bhore. (b) Dev-only header/CLI token diye temporary staff login. (c) M1 e shudhu service/store ar test, admin route M4 e.
   Recommendation: (a). Production e kichu khola thake na, M4 e shudhu session middleware jog; (b) te bhule thaka backdoor er jhuki.
2. **Shop resolve er kon ongsho M1 e?** (3.2 table, 15 er scope "`X-Shop-Host`, session, `tran_id`"). Customer session er table/code M4 e, `payments` er flow M10 e.
   Options: (a) M1 e `X-Shop-Host` resolver ar staff context er type (`shop_id`, `vendor_id`, role); "session er `shop_id` mile kina" M4 e, `tran_id` → `payments.shop_id` M10 e. (b) M1 e tinta resolver-i, test shoho (session/payment row hate boshiye).
   Recommendation: (a). Code er dhoron (route onujayi alada resolver, ek middleware na) M1 e thik hoy; baki duita jar milestone e asol data, sheikhane test.
3. **`shop create` er baki input** (3.8, 6.7). Command e `--slug --prefix --domain --owner-email` ache, kintu `shops.name`, `vendors.name/slug`, `staff.name` NOT NULL, preset ar temporary password kivabe owner pay lekha nai.
   Options: (a) `--name-bn` (lagbe), `--name-en` (optional), `--owner-name` (lagbe), `--preset` (default `organic`, 9.4); house vendor er slug = shop slug, naam = shop er naam; `branding.name` = shop er naam; temporary password `crypto/rand` diye banano, stdout e ekbar print (log e na). (b) Shob JSON stdin theke (`credentials set` er moto). (c) Password user `--owner-password-stdin` e dey.
   Recommendation: (a); password terminal e ekbar dekha jay, prothom login e bodlate hoy (8.3), log ar shell history te thake na.
4. **Public `GET /api/settings` e kon field?** (9.2 "checkout.risk er moto vitorer setting jabe na", 7.2 "checkout setting er public onsho"). Shimana spashto na.
   Options: (a) Whitelist: `branding`, `theme`, `locales`, `features`, `homepage`, `seo`, `integrations`, `checkout.payment_methods`, `checkout.return_window_days`, `marketplace.show_vendor_name`; baki (`checkout.risk`, `otp_mode`, `cod_confirmation`, `auto_cancel_unconfirmed_hours`, `sms_daily_cap`, `inventory`, `marketplace.delivery_charge_mode`, `default_commission_bps`) na. (b) Blacklist (shudhu `checkout.risk`, `sms_daily_cap` bad).
   Recommendation: (a) whitelist; notun setting default e private thake (fail-closed). `otp_mode` ar `cod_confirmation` server-i decide kore (8.7, 8.10), client `otp_required` code pay.
5. **7.2/7.7 er kon endpoint M1 e, kon pore?** 15 er M1 row e nai kintu 7.2/7.7 e ache:
   - `GET /api/settings/preview?token=`: signed preview token admin (M8) banay. Recommendation: M8.
   - `GET /api/translations?locale=`: shudhu read, M3 er website e lagbe; editor M8. Recommendation: M1 (choto) — ba M3 er shuru te.
   - `GET /api/vendors/{slug}` (single e `404`): Recommendation: M1 e na, MV e (single e shob shomoy 404, M1 er kono criteria e lage na).
   - `POST /products/{id}/images`, `PATCH .../images/order`, `DELETE /images/{id}`: R2 upload lage, 15 e M7 ("product/variant/chobi (R2)"). Recommendation: M7; M1 er product detail `product_images` theke pore (dev e SQL diye row).
   - Admin `vendors` CRUD: Recommendation: M7 ba MV (single e shudhu house vendor profile).
6. **`shops.status = 'closed'` hole public API?** (3.2 Niyom 2 shudhu `suspended` → `423` bole; 6.7 e `closed` ache). Options: (a) `404 shop_not_found`, (b) `423 shop_suspended` er moto, (c) notun code `shop_closed` (7.1 e jog). Recommendation: (a); closed shop er kichu public e dekhano lage na. Admin login: closed e-o cholbe kina M4 er age bolo.
7. **Error `message` er bhasha** (7.1: "`message` `Accept-Language` onujayi", udahoron Bangla okkhore). M0 er code e message Banglish Latin e (`"Server e shomossha hoyeche"`), ar kon jaygay bn/en lekha thakbe design e nai.
   Options: (a) `httpx` e code → `{"bn","en"}` map (Bangla okkhore ar English), `WriteError` `Accept-Language` dekhe; ochena code e `bn`. (b) Server English/fallback, client `code` theke nijer translation dekhay (Rule 4). (c) (a) + (b): server message thake, client chaile nijer key.
   Recommendation: (a); 7.1 er lekha-i mane, ar M2 er `ApiClient` `code` diye logic kore, tai client chaile override korte pare.
8. **Product list er search, sort ar paging** (6.4 er query `LIMIT 24` ar `word_similarity` order; 7.1 paging `{"items","page","limit","total"}`; 7.2 `sort` e `popular`).
   Options: (a) `q` thakle ar `sort` na dile relevance (6.4) order; `sort` dile sheta; search o 7.1 er moto paged (`limit` max 100, `total` `count(*)`); `popular` = `review_count DESC, rating_sum DESC` (column ache). (b) Search alada, shudhu 24 ta, paging na. (c) `popular` = bikri (notun column/view, `002` migration; order M6 e ashe).
   Recommendation: (a); migration lage na, M6 er por bikri-bhittik chaile design-change.
   Ranking: 6.4 bole "dorkar hole prefix mil age"; test e juktakkhor case fail korle `ORDER BY (search_text ILIKE $2 || '%' ba shobder shuru) DESC, word_similarity(...) DESC` jog korbo (6.4 er lekha onujayi, notun decision na); query bodlale 6.4 er SQL o update (design-change).
9. **Slug kivabe ashe?** (`products.slug`, `categories.slug` NOT NULL, `UNIQUE (shop_id, slug)`; URL `/api/products/{slug}`; design e niyom nai). Options: (a) Admin body te dey (Latin, `^[a-z0-9]+(-[a-z0-9]+)*$`, max 80), PATCH e bodlano jay, purono URL redirect MVP te na; duplicate → `409 slug_taken`. (b) `name.en` theke auto, duplicate e `-2`. Recommendation: (a); Bangla naam theke auto slug bhalo hoy na, admin Banglish dey (`lal-chal`). `slug_taken` 7.1 er table e notun code.
10. **Category `DELETE /categories/{id}`** (7.7; product/child category FK `ON DELETE` chhara). Options: (a) Hard delete shudhu khali hole; product ba child thakle `409 category_not_empty`; lukate `PATCH is_active=false`. (b) DELETE = `is_active = false` (soft). Recommendation: (a); FK nijei atkay, API shudhu thik code dey.
11. **Admin product create e `vendor_id`** (7.1 "shop staff `?vendor_id=` diye filter", Rule 13; create er body lekha nai). Options: (a) Body te `vendor_id` optional; shop staff (owner/admin) na dile house vendor; vendor staff er jonno session er vendor, body te onno vendor → `404`. (b) Shob shomoy house vendor (MV e bodlano). Recommendation: (a); Rule 13 ("shop = vendor" dhore na).
12. **Variant e stock** (8.12: stock er protiti bodol `inventory_movements` e; inventory admin M7). Options: (a) M1 er variant create/PATCH e `stock` field na (create e 0, `DisallowUnknownFields` e `400`); stock M7 er batch/adjust e; M3 er dev data SQL seed diye. (b) Create e `initial_stock` + `adjust` movement. Recommendation: (a); M1 e movement/batch er niyom na ana.
