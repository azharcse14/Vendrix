# Milestone er plan ar progress

`milestone` skill (`/milestone M<n>`, ba `next` skill `docs/STATUS.md` theke) protiti milestone er plan ekhane `M<n>.md` naam e likhe ([template](../../.claude/skills/milestone/plan-template.md)), approval er por kaj er shathe shathe tick kore, ar shesh e acceptance er proman (test er naam, command er output) rakhe. Notun session (`/clear` er por) ei file ar [STATUS](../STATUS.md) theke abar shuru kore.

Scope ar acceptance criteria er asol jayga `docs/design/15-milestones.md`; ekhane shudhu plan ar progress. Feature ekhon kivabe kaj kore: `docs/features/`.
