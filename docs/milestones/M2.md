## Scope (15 er row theke)
- `packages/shared` pure Dart package (Rule 10): runtime dependency shudhu `http`, `intl` (2.3); Flutter, `dart:io`, `dart:html`, `dart:ui` import na (`scripts/check-rules.sh` dhore). Website, admin, app path dependency diye ney (4.6). Local Dart SDK 3.13.7 (Flutter 3.47.9 er sathe).
- **Model** (4.3): hand-written `fromJson`/`toJson` (2.3 e `json_annotation` er moto runtime dependency allowed na, tai codegen na). JSON `snake_case` (7.1), taka `int` poisha (Rule 2), shomoy ISO 8601 UTC → `DateTime` (UTC). Kon model M2 e: Open question 1.
- **`ApiClient`** (4.3, 7.1, 11): `package:http` er `Client` inject hoy (admin `BrowserClient()..withCredentials = true`, website server e `http.Client()`, test e `MockClient`); constructor e `baseUrl` ar header (`X-Shop-Host`, `Accept-Language`, Jaspr er `X-Client-IP`/`X-Internal-Auth`; protiti request e notun `ApiClient`, ek `http.Client`). 2xx na hole 7.1 er body theke `ApiError{status, code, message, fields, details}`; client logic `code` diye, `message` shudhu dekhano. `429` e `Retry-After`. Paging `Page<T>{items, page, limit, total}` (7.1). Network/timeout/JSON na hole ki: Open question 7.
- **Repository** (4.3): M1 er public API er jonno (`GET /api/settings`, `/api/settings/version`, `/api/translations`, `/api/categories`, `/api/products`, `/api/products/{slug}`); kon gulo: Open question 1.
- **Translator** (9.8): key → lekha, kram `override[locale][key]` → `file[locale][key]` → `override[bn][key]` → `file[bn][key]` → key nijei + `onMissing` callback ("missing translation" log; pure Dart e logger na, app dey). Placeholder `{name}`; English plural `.one`/`.other`. Override `GET /api/translations?locale=` theke (M1). Content `{"bn","en"}`: `value[locale] ?? value["bn"]` (`LocalizedText`, admin API puro object dey, 7.1). Default lekha (`bn`/`en`) kothay ar kivabe load: Open question 2.
- **Format** (9.8): taka `NumberFormat('#,##,##0', locale)` (poisha thakle `'#,##,##0.00'`) + samne `৳` nije; `NumberFormat.currency` na. `bangla_digits` on → `bn` (`৳১,২৫,০০০`, `৳১৮০.৫০`), off → `en_IN` (`৳1,25,000`); poisha na thakle doshomik na (`৳১৮০`). Tarikh `DateFormat('d MMMM y', locale)` ("২৭ অক্টোবর ২০২৬"); `initializeDateFormatting` (`package:intl/date_symbol_data_local.dart`, pure Dart). Local e `intl` 0.20.3 diye dekha: duitai ashe. Timezone (Rule 5): Open question 3; locale er matrix ar minus: Open question 4.
- **Phone validation** (8.1, Rule 6): `normalizePhone(String) → String?` (`+8801XXXXXXXXX` ba `null`) ar `isValidPhone`, Go er `phone.Normalize` er hubohu niyom (Bangla shonkhya, separator, Unicode `Cf` bad, `+` shudhu shuru te ar tarpor `880`, `00880`, operator digit 3–9). Server abar normalize kore (Rule 1/6); client shudhu form e agei bhul dekhay. Test case kivabe milbe: Open question 8.
- **Theme token** (9.3, 9.4, 9.7): `deriveTokens(ThemeSettings) → ThemeTokens` (primary, primary-hover, on-primary, accent, on-accent, tint, text, text-muted, background, surface, border, radius, heading/body font) ar `contrastRatio(a, b)` (sRGB → linear, `L = 0.2126 R + 0.7152 G + 0.0722 B`, `(L1 + 0.05) / (L2 + 0.05)`), threshold 4.5 (9.3). Rong `#RRGGBB` parse; `ThemeTokens.cssVariables()` (`--color-primary` ... 9.3 er naam, website `<head>` e). Flutter `Color` e convert admin/app e (Rule 10). Derive er formula: Open question 5; warning kon jora te: Open question 6.
- `validation/` er naam ar thikana (4.3) M2 te na: oi form er milestone e (M4 naam, M6 thikana); Open question 1 er shathe.
- Tooling: `analysis_options.yaml` (`package:lints/recommended` + strict mode + `public_member_api_docs`), `.github/workflows/ci.yml` e Dart job (`QUICK_ALL=1 QUICK_PARTS=dart bash scripts/quick-check.sh`), `quick-check.sh` bodlano lage na (`dart_part packages/shared dart` ache). ## Open question (uttor: shob recommendation, design v1.12)

1. **M2 te kon model, repository ar validation?** (4.3 e `Product, Variant, Category, Cart, Order, Settings, Theme`, `validation/` e phone, naam, thikana). Cart, order, login er API (M4–M6) ekhono design er table e ache kintu code nai, response er shape thik hoyni.
   Options: (a) Shudhu M1 er public API er model ar repository (settings, translations, category, product list/detail, `Page`, `LocalizedText`); cart, order, user, admin model ar naam/thikana validation oi milestone e (M4, M5, M6, M7). (b) 4.3 er shob model ekhon-i 7.x er table theke. (c) (a) + Cart/Order er khali skeleton.
   Recommendation: (a). Asol response chhara model likhle pore bodlate hoy; protiti milestone e API er sathe model ek commit e.
2. **Default UI lekha (`bn.json`, `en.json`) pure Dart e kivabe load?** (9.8 bole `packages/shared/lib/l10n/bn.json`.) Pure Dart e `dart:io` na, admin (Flutter web) e file pora jay na; `import` diye JSON ashe na.
   Options: (a) JSON-i source, `tool/gen_l10n.dart` `lib/l10n/messages.g.dart` (const `Map`) banay, test dekhe JSON ar generated mile kina. (b) Dart file-i source: `lib/l10n/bn.dart`, `en.dart` (`const Map<String, String>`); 9.8 er lekha bodlano (design-change). (c) JSON thake, protiti app nijer asset/file hishebe load kore `Translator` ke `Map` dey.
   Recommendation: (b). Ek file, codegen ba asset config na, compile e key ache kina dhora pore; admin override `translations` table e (M8) thake-i. Note: backend er SMS template (`sms.*`, 8.16) er default Go o lagbe (M4); Go `embed` `packages/` e pouchay na, tai oita M4 e alada decision (Go e nijer `sms.*` default, ba JSON copy).
3. **Tarikh/shomoy shop er timezone e kivabe?** (Rule 5: `shops.timezone`, default `Asia/Dhaka`; API UTC dey, 7.1.) Pure Dart e IANA timezone database nai, `toLocal()` device/server er timezone dey (Jaspr server UTC te). 2.3 e `timezone` package nai.
   Options: (a) `formatDate(DateTime utc, locale, {String timeZone = 'Asia/Dhaka'})`: choto map `{'Asia/Dhaka': +6:00}` (DST nai), ochena zone e `ArgumentError`; multi-tenant e onno timezone ele (MT) package/design-change. (b) `package:timezone` jog (2.3 bodlate hobe, ~400 KB data web bundle e). (c) API public response e shop er local shomoy o pathay.
   Recommendation: (a). Ekhon shudhu Bangladesh; `ponytail:` comment e shima ar upgrade path.
4. **Format er locale matrix ar minus taka.** 9.8 bole `bangla_digits` on → `bn`, off → `en_IN`, kintu UI bhasha `en` hole ki, ar `bangla_digits` off kintu bhasha `bn` hole tarikh er mash er naam kon bhashay, ar refund/discount er minus kivabe — lekha nai.
   Options: (a) Digit Bangla shudhu jodi bhasha `bn` **ar** `bangla_digits` on; mash er naam UI bhasha theke (`bn` → "অক্টোবর"), digit upore niyome (`DateFormat.useNativeDigits`) — fole `bn` + off = "27 অক্টোবর 2026"; minus: `-৳১৮০` (chinho ৳ er age). (b) `bangla_digits` bhasha nirbishesh (en UI teo Bangla digit). (c) Minus `৳-১৮০` ba bracket.
   Recommendation: (a). English page e Bangla digit porte kothin; `-৳` common practice.
5. **Derived token er formula** (9.3 er table e kotha, hishab na). "primary 8% gaḍho", "background er cheye ektu halka/shada", "text 12%", muted "text er dike shorano" — kon color space e mix, koto step.
   Options: (a) Shob mix sRGB (gamma) channel e linear interpolate, round: `primary-hover = mix(primary, #000000, 8%)`, `surface = mix(background, #FFFFFF, 50%)` (background shada hole surface o shada, card border diye alada), `border = mix(background, text, 12%)`, `text-muted` 65% text theke shuru kore 1% kore text er dike barano jotokkhon `contrast(muted, background) ≥ 4.5` (ar `surface` er upore o); `on-primary`/`on-accent` = shada ba `text`, je ta contrast beshi (9.3). (b) HSL lightness −8% / +x%. (c) OKLCH (perceptual; beshi code).
   Recommendation: (a). Choto, CSS `color-mix(in srgb, ...)` er sathe mile, test e preset er exact hex golden; 9.3 e formula likhe (design-change) Go (M8) o ekoi.
6. **Contrast warning kon jora te?** (9.3: "lekha ar tar background", 4.5.) Kon kon jora "lekha/background" ta lekha nai; `primary` link ar dam er lekha hishebe-o use hoy.
   Options: (a) `text`/`background`, `text`/`surface`, `text`/`tint`, `on-primary`/`primary`, `on-accent`/`accent`, `primary`/`background` (link, dam); shob 4.5; result `List<ContrastWarning{pair, ratio}>`, warning er lekha translation key `theme.low_contrast`. (b) Shudhu admin er 5 rong er `text`/`background`. (c) (a) kintu boro lekha (button) e 3:1.
   Recommendation: (a). Ek threshold, shohoj; `on-*` derive e auto shada/text bache, tai oigulo shudhu dui rong-i kharap hole warning dey.
7. **`ApiClient` e network/timeout/non-JSON error ar timeout.** 7.1 shudhu server er error body bole.
   Options: (a) Shob `ApiError` e: network fail → `status 0, code 'network_error'`; timeout (default 15 second, constructor e bodlano jay) → `code 'timeout'`; 2xx na kintu JSON na (Caddy/Cloudflare HTML 502) → `code 'internal'`, `status` asol; retry na (idempotent na hoya POST e bipod; GET retry app er bloc e). Notun client code dui ta (`network_error`, `timeout`) translation key `error.*` e. (b) Alada exception class (`NetworkException`), app duita dhore. (c) (a) + GET e ekbar auto retry.
   Recommendation: (a). App ek type (`ApiError.code`) dhore UI dekhay, 7.1 er "logic `code` diye" niyom er moto.
8. **Phone er Dart test Go er sathe kivabe mile?** (8.1: Go er code-i spec.)
   Options: (a) Go er `TestNormalize` er `ok`/`bad` list Dart test e hubohu copy, comment e Go file er path; feature doc e "Go bodlale Dart o". (b) Shared fixture `packages/shared/test/fixtures/phone_cases.json`, Go test `../../../packages/shared/...` theke pore, Dart o pore. (c) Go er test file parse kore Dart test.
   Recommendation: (a). Niyom bochore ekbar bodlay; (b) te Go module er baire file er nirbhorota. Drift atkate `phone.md` er "Bodlanor age mone rakho" ar design-reviewer.
9. **Dev tooling ar version** (2.3 e shudhu runtime package).
   Options: (a) `dev_dependencies`: `test`, `lints` (runtime e jay na, 2.3 bhange na); `environment.sdk` Jaspr 0.23.5 ar Flutter 3.47.9 (Dart 3.13.7) duitar sathe mile emon minimum (`^3.9.0`, step 1 e `dart pub get` diye dekha); `intl: ^0.20.2` (Flutter er `flutter_localizations` er pin er sathe conflict na), `http: ^1.6.0`; library tai `pubspec.lock` commit na (app gulor lock asol, 4.6); CI te `dart-lang/setup-dart` Dart `3.13.7` (Flutter 3.47.9 er Dart; Flutter job M7 e), action SHA pin. (b) CI te ekhon-i Flutter setup (admin er jonno-o). (c) `pubspec.lock` commit.
   Recommendation: (a).
